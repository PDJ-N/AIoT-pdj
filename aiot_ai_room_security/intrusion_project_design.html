AI 기반 방 침입 감지 시스템 기획 및 데이터 구조 설명서

aiot_ai_room_security 프로젝트의 기획 의도, 시스템 구성, 데이터 구조, 모듈 역할, 이벤트 처리 흐름을 보고서 제출용으로 정리한 HTML 문서이다.

기획 설명서 데이터 구조도 모듈 구조 CSV 로그 보고서 참고용

1. 프로젝트 기획

본 프로젝트는 Raspberry Pi 5, PIR 인체감지 센서, USB 웹캠, OpenCV DNN MobileNet SSD, 능동 부저, 텔레그램 봇 API, CSV 로그 파일을 이용하여 방 침입 감지 시스템을 구현하는 것을 목표로 한다.

단순 PIR 센서만 사용하면 사람 외의 움직임에도 반응할 수 있으므로, PIR 센서는 1차 움직임 감지 트리거로 사용하고 OpenCV AI 객체검출은 2차 확인 단계로 사용한다. AI 모델이 웹캠 프레임 안에서 person 객체를 기준 confidence 이상으로 찾으면 실제 침입 이벤트로 판단한다.

이 시스템의 AI 기능은 얼굴 신원 인식이 아니라, 수업에서 사용한 MobileNet SSD 기반 person 객체검출이다. 프로젝트 목적은 “방 안에 사람이 있는가”를 판단하는 것이다.

2. 핵심 목표

  • PIR 센서로 방 안의 움직임을 빠르게 감지한다.
  • OpenCV DNN으로 사람이 맞는지 한 번 더 확인한다.
  • 침입 이벤트 발생 시 능동 부저로 현장 경고음을 출력한다.
  • 텔레그램으로 사용자에게 메시지와 사진을 전송한다.
  • CSV 로그로 이벤트 시간, 종류, confidence, 이미지 경로를 저장한다.
  • cooldown으로 중복 알림을 방지한다.
  • MOCK_MODE로 하드웨어 없이 프로그램 흐름을 테스트한다.

4. 시스템 구조도

시스템은 입력부, 처리부, 출력부로 나눌 수 있다. PIR 센서와 웹캠은 입력 데이터를 만들고, Raspberry Pi의 Python 프로그램은 센서값과 AI 결과를 판단하며, 부저/텔레그램/CSV 로그는 결과 출력과 기록을 담당한다.

입력부
PIR 센서 방 안 움직임 감지 Signal → GPIO16
USB 웹캠 현재 방 화면 입력 OpenCV VideoCapture
환경변수 설정 token, chat_id, mock, camera config.py

Raspberry Pi 5 처리부

1. 센서 감지 sensor.read_motion()으로 PIR 값을 읽는다.
2. AI 분석 vision_ai.detect_person()으로 person 객체와 confidence를 구한다.

이미지/CSV 저장 감지 사진과 로그 기록 captures/, logs/

5. 동작 흐름도

아래 흐름도는 프로그램이 실행된 뒤 침입 이벤트를 판단하고 처리하는 전체 순서를 나타낸다. 핵심은 PIR 센서가 먼저 움직임을 감지하고, 그 다음 AI가 사람이 맞는지 확인한다는 점이다.

1 프로그램 시작 설정값을 읽고 대기 상태로 진입한다. main.py
2 PIR 반복 확인 움직임이 있는지 계속 읽는다. GPIO16
3 움직임 감지? PIR 값이 1이면 웹캠과 AI 분석으로 넘어간다. 아니면 계속 대기
4 웹캠 프레임 획득 USB 웹캠에서 현재 화면을 읽는다. frame
5 OpenCV DNN 분석 MobileNet SSD로 person 객체를 탐지한다. confidence
6 사람 감지? confidence가 기준값 이상인지 확인한다. 기본 기준 0.50
7 cooldown 확인 최근 알림 후 10초가 지났는지 확인한다. 중복 알림 방지
8 침입 이벤트 처리 사진 저장, 부저, 텔레그램, 로그 저장을 수행한다. 최종 출력
사람이 감지되지 않은 경우

AI confidence가 기준값보다 낮으면 침입으로 판단하지 않고 다시 PIR 감지 대기 상태로 돌아간다.

사람이 감지된 경우

cooldown이 끝난 상태라면 침입 이벤트로 판단하고 경고음, 텔레그램, CSV 로그를 실행한다.

7. 모듈 구조

main.py 프로그램 진입점이다. PIR 감지, AI 분석, cooldown, 이미지 저장, 부저, 텔레그램, 로그 기록을 연결한다.
config.py GPIO 핀, 모델 경로, confidence 기준, 텔레그램 정보, 카메라 표시, MOCK_MODE를 관리한다.
sensor.py PIR 센서 값을 읽고 움직임 감지 여부를 반환한다.
buzzer.py 능동 부저를 켜고 끈다. 침입 이벤트 시 지정 시간 동안 경고음을 출력한다.
vision_ai.py 웹캠 프레임을 읽고 OpenCV DNN으로 사람을 탐지한다. 이미지 저장과 카메라 화면 표시도 담당한다.
telegram_notifier.py 텔레그램 메시지와 사진 전송을 담당한다. token이 없으면 전송만 건너뛴다.
logger.py logs/event_log.csv에 침입 이벤트 한 줄을 추가한다.
download_models.py 수업자료 모델 파일 준비가 안 될 때 필요한 모델 파일을 직접 다운로드한다.
requirements.txt 실행에 필요한 Python 라이브러리 목록이다.

8. 처리 흐름 상세

  1. main.py가 실행되고 시스템 대기 메시지를 출력한다.
  2. 무한 루프에서 sensor.read_motion()으로 PIR 센서 값을 확인한다.
  3. PIR 센서가 움직임을 감지하면 vision_ai.detect_person()을 호출한다.
  4. vision_ai.py가 웹캠 프레임을 읽고 MobileNet SSD 모델을 실행한다.
  5. 모델 결과에서 class id가 1인 person 객체를 찾는다.
  6. confidence가 기준값 이상이면 침입 이벤트로 판단한다.
  7. cooldown 시간 안이면 알림과 부저를 생략하고 대기로 돌아간다.
  8. cooldown이 끝났다면 이미지를 저장하고 부저를 울린다.
  9. 텔레그램 메시지와 사진을 전송한다.
  10. CSV 로그에 이벤트를 기록한다.
  11. Ctrl+C 또는 OpenCV 창의 q 키 입력 시 안전하게 종료한다.

9. 주요 데이터 구조

데이터 자료형 생성 위치 설명

13. 이벤트 판단 의사코드

while True:
    if 카메라 화면 표시 옵션이 켜져 있음:
        웹캠 프레임을 화면에 표시

    if PIR 센서가 움직임을 감지하지 않음:
        계속 대기

    if PIR 센서가 움직임을 감지함:
        웹캠 프레임 읽기
        OpenCV DNN으로 person 객체 탐지

    if person confidence < 기준값:
        침입으로 판단하지 않음

    if person confidence >= 기준값:
        if cooldown 중:
            중복 알림 생략
        else:
            이미지 저장
            부저 울림
            텔레그램 메시지/사진 전송
            CSV 로그 기록

14. 보고서용 설명 문장

본 프로젝트는 PIR 인체감지 센서와 OpenCV DNN MobileNet SSD 객체검출을 결합한 Raspberry Pi 기반 AIoT 방 침입 감지 시스템이다. PIR 센서는 사람이나 물체의 움직임을 빠르게 감지할 수 있지만, 사람 외의 움직임에도 반응할 수 있다. 따라서 본 시스템은 PIR 센서를 1차 감지 장치로 사용하고, USB 웹캠과 AI 사람 객체검출을 2차 확인 단계로 사용하여 침입 판단의 신뢰도를 높였다.

침입으로 판단되면 능동 부저를 울려 현장에서 경고음을 출력하고, 텔레그램 봇 API를 통해 사용자에게 메시지와 사진을 전송한다. 또한 모든 침입 이벤트는 CSV 파일에 시간, 이벤트 종류, 메시지, AI confidence, 이미지 경로와 함께 저장된다. 이 구조는 센서 입력, AI 영상 분석, GPIO 출력, 네트워크 알림, 데이터 기록을 통합한 AIoT 응용 사례이다.

15. 장점과 한계

구분 내용
장점 PIR 센서와 AI 객체검출을 함께 사용하여 단순 움직임 감지보다 침입 판단 신뢰도를 높일 수 있다.
장점 텔레그램 메시지와 사진 전송으로 사용자가 원격에서 상황을 확인할 수 있다.
장점 CSV 로그와 저장 이미지를 통해 결과보고서 작성과 시연 자료 확보가 쉽다.
한계 조명, 웹캠 각도, 사람과 카메라 거리, 모델 파일 경로에 따라 탐지 성능이 달라질 수 있다.
한계 OpenCV 카메라 창은 라즈베리파이 Desktop 환경에서 실행해야 정상적으로 표시된다.
